The fight ends. The prediction pays out. The brand instrument reprices. Margin adjusts. On fragmented venues, these execute as separate steps — arbitrageurs take the difference between them. On Moxie, they execute in one atomic settlement, by consensus rule. No gap to extract.

typescript · Tier 1 SDK 
import { Moxie } from "@moxie/sdk";

const moxie = new Moxie({
  token: process.env.MOXIE_TOKEN!,
  region: "us-east-1",
});

// 1. Pre-flight the 23-domain compliance tensor.
const preflight = await moxie.compliance.preflight({
  brand_id: "bout",
  entity_ids: [entityId],
});
// { allowed: true, commitment: "0x...", ttl_ms: 60_000 }

// 2. Issue a prediction position; receipt participates in block commit.
const batch = await moxie.settlements.batch({
  idempotency_key: "ufc-317-card-1",
  items: [
    { type: "pay_winners", market_id, winners },
    { type: "issue_asset", template_id, to: winners },
    { type: "net_margin",  player_ids: winners },
  ],
  finality_target: "finalized",
  compliance_commitment: preflight.commitment,
});
const receipt = await batch.receipt();
// { batch_root, phase1_root, final_state_root, block }

You set the budget. You set what moves it can make. You set how long its authority lasts. Every action resolves to you as the named person in charge, every trade lands in the audit trail. Revoke in one call when you want back in the chair.

Moxie is the first market built for agents as first-class callers: one settlement path, one audit trail, whether a human or a model is driving.

python · agent caller 
from moxie_sdk import Moxie, AgentInvocation

moxie = Moxie(credential="mxk_sk_agent_...")

# Delegation: human principal → agent, scoped + TTL'd.
inv = AgentInvocation(
    principal="did:moxie:alice",
    scope=["settlements:write", "margin:read"],
    caveats={"max_cost_usd": "500.0", "ttl_s": 3600},
    crypto_epoch=12,
)

# Same compliance preflight as a human backend.
pf = moxie.compliance.preflight(brand_id="bout", entity_ids=[e])

# Same settlement path. Typed errors. Hashed receipt.
batch = moxie.settlements.batch(
    idempotency_key="liq-9f2a",
    items=[{"type": "liquidate", "player_id": p}],
    invocation=inv,
    compliance_commitment=pf.commitment,
)

# Audit record carries delegation lineage.
print(batch.receipt().audit_log)
# [ principal=did:moxie:alice, agent=..., depth=3, epoch=12 ]
